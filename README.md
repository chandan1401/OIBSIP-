# Lumen Brew – Coffee Landing Page

**OIBSIP Track:** Web Development and Designing  
**Level / Task:** Level 1 - Task 1  
**Project:** Lumen Brew

## Project description
Lumen Brew is a responsive coffee landing page for a fictional small-batch coffee brand. It introduces the brand, highlights its features, shares customer testimonials, and provides contact information.

## Technologies used
- HTML5
- CSS3

## Project structure
```text
OIBSIP/
└── Web-Development-and-Designing-Level-1-Task-1-Lumen-Brew/
    ├── index.html
    ├── style.css
    └── README.md
```

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or package installation are required.

## Features
- Navigation links to page sections
- Hero section with a call-to-action
- Three feature cards
- About section with brand statistics and a CSS coffee-cup illustration
- Customer testimonials
- Contact and social links
- Responsive layout for smaller screens
